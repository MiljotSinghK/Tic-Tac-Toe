# Tic-Tac-Toe Game in Python

A simple command-line Tic-Tac-Toe game built using Python. The game allows a human player to play against a rule-based computer opponent.

## Features
- **Interactive Command-Line Interface**: Easy-to-use numbered grid for placing moves.
- **Rule-Based Opponent Logic**: The AI attempts to block your winning moves and seize opportunities to win the game.
- **Game State Tracking**: Automatically detects wins, losses, and ties.

## How to Play
1. Run the script using Python:
   ```bash
   python TicTacToe.py
   ```
2. The board will display positions numbered from 1 to 9:
   ```
    1 | 2 | 3
   ---+---+---
    4 | 5 | 6
   ---+---+---
    7 | 8 | 9
   ```
3. You play as **O** and the computer plays as **X**.
4. Enter a number between 1 and 9 to place your mark on the corresponding cell.
5. The game ends when either you or the computer gets three marks in a row (horizontally, vertically, or diagonally), or when all spaces are filled resulting in a tie.

- Python 3.x
